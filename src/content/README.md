# Editable website content

Each website tab has one clearly commented content file:

- `site.content.ts` — brand, contacts, announcement, and shared navigation
- `home.content.ts` — homepage hero and homepage section settings
- `shop.content.ts` — shop/filter/sorting labels
- `product.content.ts` — shared product-details labels
- `footer.content.ts` — footer columns and links

Product and category records can be edited visually at `/admin`, or in
`src/data/catalog.ts` when changing the source defaults.

Do not edit `dist/`. It is regenerated by `npm.cmd run build`.
